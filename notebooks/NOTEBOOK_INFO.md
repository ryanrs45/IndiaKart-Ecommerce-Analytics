# IndiaKart Analysis Notebooks

This folder is reserved for the Python and Jupyter Notebook analysis used in the IndiaKart E-Commerce Analytics project.

The project workflow included:

- Data loading
- Data inspection
- Duplicate checking
- Data cleaning
- Exploratory Data Analysis
- KPI preparation
- Data preparation for Power BI

The main project deliverables are available in the `dashboard`, `reports`, and `screenshots` folders.
