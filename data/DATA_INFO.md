# IndiaKart Dataset Information

The full dataset files are not included in this repository.

This project uses 8 datasets:

| Dataset | Records |
|---|---:|
| Customers | 10,000 |
| Inventory | 1,000 |
| Order Items | 100,000 |
| Orders | 50,000 |
| Payments | 50,000 |
| Products | 1,000 |
| Returns | 10,000 |
| Suppliers | 200 |

## Data Quality Checks

- Duplicate rows were checked across all datasets.
- No duplicate rows were found.
- Data was cleaned and prepared before analysis.
- Relationships were created between customers, orders, products, payments, inventory, suppliers, and returns.

## Note

The datasets are excluded from this repository to keep the project lightweight and focused on the analytical workflow, dashboard, report, and business insights.
